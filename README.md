## 📌 订阅与使用注意事项

### 1. 看清套餐规则

购买前确认流量额度、有效期、重置日期及节点倍率。按月重置流量和不限时流量包的使用规则可能不同。

### 2. 确认客户端兼容性

不同服务使用的协议可能不同。先查看支持的系统、客户端及同时连接数量限制，再进行配置。

### 3. 首次使用优先短周期

连接表现与所在地、运营商和使用时段有关。首次订阅可从较短周期开始，避免一次购买过长时间。

### 4. 妥善保管订阅链接

个人订阅链接可能包含访问凭证，请勿发布在公开仓库、Issue 或评论区。分享截图时，也应隐藏账号和订阅信息。

### 5. 遇到异常先排查

检查本地网络、套餐有效期和剩余流量，再更新订阅、查看服务公告。节点超时不一定意味着服务停止运营。

### 6. 保存入口与支持渠道

将常用入口加入书签，并了解站内支持方式与退款规则。域名、套餐及活动可能调整，以各站内说明为准。
